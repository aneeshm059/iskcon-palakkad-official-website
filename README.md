# ISKCON Palakkad — React Homepage

React + Vite implementation of the approved ISKCON Palakkad graphical website direction.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The supplied Radha Krishna Bhakthi Yoga Mandiram architectural image is included locally as `temple-architecture.png` and used in the Temple Project section.
- Reference imagery for other sections is currently remote placeholder imagery and should be replaced with official ISKCON Palakkad photographs before production.
- Official address, phone, email, legal/entity information and final policy wording should be completed before Razorpay review.
- Hash-based navigation is used intentionally for this prototype so it can be deployed as a simple static Vite site.
